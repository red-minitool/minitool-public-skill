# 离线 H5 基线

通用小工具开发和改写时先核对以下容器约束，官方文档不可用时也可据此完成基础实现。涉及具体 API、客户端版本或平台资源策略时，按 [召回指引](recall.md) 核对线上契约。ZIP 结构、压缩命令和交付检查见 [ZIP 打包与验收](zip-artifact-spec.md)。

- Android 以 Chrome / WebView 61 为最低 Web 兼容基线。更高版本能力以检测结果增强。依赖更新的语法时，用已有构建链输出目标浏览器可解析的代码。
- 页面以包内同源路径引用资源。运行时使用包内经典脚本和 `addEventListener`，容器会拦截内联脚本、行内事件、动态执行和外网请求。
- 容器从 `index.html` 启动。JS 执行前保留可理解的界面或加载提示，具体启动方案按 `perf.startup` 召回。
- 静态资源外移以官方章节公布的目录、文件类型和客户端条件为准。上传包仍要包含所引用的资源。OSS 的上传或分发地址不能作为页面直连外部服务的依据。
- 离线时优先使用浏览器基线和纯本地交互。客户端版本、平台权限或授权无法确认时，保留基础交互并标明对应能力待核验。

细则通过 [召回指引](recall.md) 查询 `resource-rules`、`perf.startup`。
